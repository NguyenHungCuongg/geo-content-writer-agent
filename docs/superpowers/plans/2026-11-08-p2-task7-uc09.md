# Phase 2 Task 7 (UC-09: Workflow LangGraph, Checkpoint, Resume, Duyệt) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng workflow LangGraph cho UC-09 (`prompt_set → plan → research → write → fact_check → approve`) có lưu checkpoint, resume sau khi tắt chương trình, nén context đủ 5 mục theo tiêu chí 3, cổng phê duyệt con người (`interrupt`), CLI và bộ 6 eval case.

**Architecture:** `agent/loop.py` mở rộng `Checkpoint` thêm `completed_steps` và hàm `check_checkpoint` kiểm đủ 5 mục bắt buộc; `agent/trace.py` thêm sự kiện `node` và nạp lại các dòng trace cũ khi resume cùng `run_id`. `agent/uc09.py` định nghĩa `CalendarItem`, `ContentCalendar` (validator chống cannibalization và kiểm internal link), `plan_calendar`, `ApprovalDecision` và CLI (`start`, `resume`, `approve`). `agent/graph.py` đóng gói `StateGraph` của LangGraph với 6 node, lưu state thuần JSON qua checkpointer Postgres (hoặc checkpointer lưu file/RAM khi chạy offline/test), hỗ trợ tạm dừng tại `approve` bằng `interrupt()` và khôi phục đúng điểm dừng sau khi tiến trình tắt.

**Tech Stack:** Python 3.12, `langgraph>=1.0`, `langgraph-checkpoint-postgres`, `psycopg[binary]>=3.2`, Pydantic v2, pytest.

**Spec:** [docs/roadmap/phase-2.md](../../roadmap/phase-2.md) mục "Task 7: UC-09, workflow LangGraph" (issues #17, #26) và [docs/guide/geo-content-writer-agent-requirement.md](../../guide/geo-content-writer-agent-requirement.md) mục UC-09.

## Global Constraints

- Gọi LLM chỉ qua interface `LLM` của `agent/llm.py` và `run_agent` của `agent/loop.py`; không thêm `langchain-google-genai` (D-13).
- State của LangGraph chỉ chứa dữ liệu JSON (`model_dump(mode="json")`), không chứa object Pydantic hay connection.
- Khi resume sau `interrupt`, LangGraph chạy lại node `approve` từ đầu: không đặt lời gọi LLM hay lệnh ghi trace trước `interrupt()` trong node `approve` (D-15).
- Nút duyệt bị khoá (ném `ApprovalBlockedError`, backend trả 409) khi bài còn claim có số liệu chưa `supported` (`blocking_claims(report)` khác rỗng).
- Từ chối lần 1 quay về `revise_uc03` kèm lý do rồi `fact_check`; từ chối lần 2 chuyển bài sang `failed` và đi tiếp bài sau.
- Xử lý lỗi node (K5): `AgentStopped` → bài `failed` kèm lý do, lịch chạy tiếp; `LLMError` → dừng run, ghi `error`, resume được sau.
- Mở file văn bản luôn với `encoding="utf-8"`.
- Nhánh `feature/p2-task7-uc09` tách từ `main`; hỏi người dùng trước khi `git push` hoặc tạo PR (AGENTS.md).
