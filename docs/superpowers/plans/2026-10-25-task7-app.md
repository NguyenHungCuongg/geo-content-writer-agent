# Task 7 (App gọi agent) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Người dùng nhập brief + 1-3 chủ đề trên web app, thấy từng bước UC-01 chạy theo thời gian thực qua SSE, rồi thấy `BrandProfile` (kèm `missing_info`, câu hỏi làm rõ, khẳng định cần chứng minh) và `PromptSet` cuối cùng. Lỗi hiện thành thông báo dễ hiểu kèm `run_id`.

**Architecture:** Backend FastAPI một file (`app/backend/main.py`). `POST /runs` tạo `Tracer(uuid4().hex)`, cất vào dict `RUNS` trong RAM, rồi chạy `run_uc01` bằng `BackgroundTasks` (sync, chạy trong threadpool). `GET /runs/{run_id}/events` là generator SSE (`fastapi.sse.EventSourceResponse`): đọc dần `tracer.events`, mỗi event gửi thành một dòng `data:` JSON, đóng stream ngay sau event `output` hoặc `error`. Run không còn trong RAM (server đã khởi động lại) thì đọc lại `traces/<run_id>.jsonl`. File này do Task 6 ghi; chưa có file thì trả 404. Frontend React + Vite + TypeScript gọi backend qua proxy của Vite dev server, nên không cần CORS.

**Tech Stack:** FastAPI ≥ 0.135 (`fastapi.sse` có từ bản này; đã kiểm 0.134 chưa có), uvicorn, pytest + `fastapi.testclient`, React + Vite (template `react-ts`), Node 24, GitHub Actions `actions/setup-node@v5`.

**Spec:** [docs/roadmap/phase-1.md](../../roadmap/phase-1.md) mục "Task 7: App gọi agent" (issue #8). ## Review Focus

1. Agent ném exception ngoài 4 loại đã biết (`InputError`, `ConfigError`, `LLMError`, `AgentStopped`), ví dụ bug hoặc `RuntimeError` từ SDK. Khi đó trace không có event kết thúc, stream chờ mãi và UI quay vòng mãi. Mong đợi: backend ghi thêm `error` với `reason="internal_error"` rồi đóng stream. Kiểm ở `test_unexpected_exception_ends_stream_with_error` (Task A).
2. Lỗi đã biết, ví dụ `repair_failed`, đã được loop ghi `error`. Backend không được ghi thêm một `error` nữa, nếu không UI sẽ hiện 2 thông báo lỗi. Kiểm ở `test_agent_stop_has_single_error_event` (Task A).
3. `run_id` trong URL là dữ liệu từ ngoài. Trên Windows, `..%5C..%5C.env` có thể làm nhánh đọc file trace đọc ra ngoài `traces/`. Mong đợi: chỉ chấp nhận đúng 32 ký tự hex thường, sai thì 422. Kiểm ở `test_malformed_run_id_rejected` (Task B).
4. File trace của một run bị cắt ngang khi server tắt (không có `output`/`error` ở cuối). Mong đợi: stream gửi hết các dòng có trong file rồi đóng, không chờ mãi; UI báo run bị gián đoạn. Kiểm ở `test_trace_file_without_terminal_event_ends_stream` (Task B).
5. `EventSource` của trình duyệt tự kết nối lại khi server đóng stream. Nếu không đóng phía client, timeline bị nhân đôi và trình duyệt gọi lại `/events` mãi. Mong đợi: client đóng `EventSource` ngay khi nhận `output`/`error`, và khi `onerror`. Kiểm bằng tay ở Task C Step 7 (tab Network chỉ có 1 request `/events` cho mỗi run).

```python
"""Test backend FastAPI bằng FakeLLM: không gọi mạng."""

import asyncio
import json

import pytest
from fastapi.testclient import TestClient
from test_uc01 import BRIEF, PROFILE, TOPIC, prompt_set, reply

from agent.llm import FakeLLM
from agent.trace import Tracer
from app.backend import main

client = TestClient(main.app)


@pytest.fixture
def use_llm():
    def use(llm):
        main.app.dependency_overrides[main.get_llm] = lambda: llm
    yield use
    main.app.dependency_overrides.clear()


def start(brief: str = BRIEF, topics: tuple[str, ...] = (TOPIC,)) -> str:
    r = client.post("/runs", json={"brief": brief, "topics": list(topics)})
    assert r.status_code == 200
    return r.json()["run_id"]


def events(run_id: str) -> list[dict]:
    with client.stream("GET", f"/runs/{run_id}/events") as r:
        assert r.status_code == 200
        assert r.headers["content-type"].startswith("text/event-stream")
        return [json.loads(line.removeprefix("data: "))
                for line in r.iter_lines() if line.startswith("data: ")]


def test_run_streams_events_until_output(use_llm):
    use_llm(FakeLLM(reply(PROFILE), reply(prompt_set())))
    run_id = start()
    got = events(run_id)

    assert len(run_id) == 32
    assert got[0]["event"] == "input"
    assert got[-1]["event"] == "output"
    assert len(got[-1]["prompt_set"]["prompts"]) == 32
    assert {e["run_id"] for e in got} == {run_id}


def test_bad_input_streams_error_without_calling_llm(use_llm):
    llm = FakeLLM(reply(PROFILE))
    use_llm(llm)
    got = events(start(brief="   "))

    assert [e["event"] for e in got] == ["input", "error"]
    assert got[-1]["reason"] == "InputError"
    assert llm.calls == []


class BrokenLLM:
    model = "broken"

    def generate(self, *args, **kwargs):
        raise RuntimeError("boom")


def test_unexpected_exception_ends_stream_with_error(use_llm):
    use_llm(BrokenLLM())
    got = events(start())

    assert got[-1]["event"] == "error"
    assert got[-1]["reason"] == "internal_error"
    assert "RuntimeError: boom" in got[-1]["message"]


def test_agent_stop_has_single_error_event(use_llm):
    use_llm(FakeLLM(reply(PROFILE), reply({"prompts": []})))  # sai luật mãi -> repair_failed
    got = events(start())

    errors = [e for e in got if e["event"] == "error"]
    assert len(errors) == 1
    assert errors[0]["reason"] == "repair_failed"


def test_unknown_run_returns_404():
    assert client.get(f"/runs/{'0' * 32}/events").status_code == 404


def test_rejects_oversized_brief():
    body = {"brief": "a" * (main.MAX_BRIEF_CHARS + 1), "topics": [TOPIC]}
    assert client.post("/runs", json=body).status_code == 422


def test_follow_yields_events_logged_later():
    tracer = Tracer("r1")
    tracer.log("input", brief=BRIEF, topics=[TOPIC])

    async def consume() -> list[str]:
        async def finish_later():
            await asyncio.sleep(0.05)
            tracer.log("output", brand_profile={}, prompt_set={})

        task = asyncio.create_task(finish_later())
        got = [e["event"] async for e in main.follow(tracer.events)]
        await task
        return got

    assert asyncio.run(consume()) == ["input", "output"]
```

- `RunRequest(BaseModel)`: `brief: str = Field(max_length=MAX_BRIEF_CHARS)`, `topics: list[str]`. Không kiểm brief rỗng hay số chủ đề ở đây: `run_uc01` đã kiểm và ghi `error` vào trace (HR-05: run bị từ chối cũng có trace).
- `RUNS: dict[str, Tracer] = {}` kèm comment `# ponytail: giữ mọi run trong RAM tới khi tắt server; Phase 2 chuyển sang Postgres (D-04)`.
- `get_llm() -> LLM | None`: trả `None`.
- `create_run(req, background: BackgroundTasks, llm = Depends(get_llm)) -> dict[str, str]`: tạo `Tracer(uuid4().hex)`, ghi vào `RUNS` **trước** khi trả response (client mở `/events` ngay sau đó), rồi `background.add_task(execute_run, req, llm, tracer)`.
- `execute_run(req: RunRequest, llm: LLM | None, tracer: Tracer) -> None`: gọi `run_uc01(req.brief, req.topics, llm=llm, tracer=tracer)` và bắt mọi `Exception`. Nếu event cuối của `tracer.events` chưa phải `error` thì `tracer.log("error", reason="internal_error", message=f"{type(e).__name__}: {e}")`. Luôn gọi `log.exception("run %s lỗi", tracer.run_id)` (logger `logging.getLogger(__name__)`).
- `follow(events, live=True)`: async generator. Giữ chỉ số event đã gửi, yield lần lượt từng event mới. Dừng **ngay sau** khi yield một event có `event` thuộc `TERMINAL`. Hết event mà `live=False` thì dừng; `live=True` thì `await asyncio.sleep(POLL_S)` rồi đọc tiếp.
- `find_events(run_id: str) -> tuple[list[dict], bool]`: dependency. Run có trong `RUNS` thì trả `(tracer.events, True)`, không có thì `HTTPException(404, "Không tìm thấy run")`. Phải là dependency vì code trong thân generator chỉ chạy sau khi header 200 đã gửi đi, nên raise 404 trong đó không có tác dụng.
- `@app.get("/runs/{run_id}/events", response_class=EventSourceResponse)` `async def run_events(source = Depends(find_events)) -> AsyncIterable[dict]`: `async for e in follow(*source): yield e`. Yield dict trực tiếp thì FastAPI tự JSON hoá vào `data:` và tự gửi ping giữ kết nối mỗi 15 giây.

def write_trace(directory, run_id: str, lines: list[dict]) -> None:
    text = "".join(json.dumps(line, ensure_ascii=False) + "\n" for line in lines)
    (directory / f"{run_id}.jsonl").write_text(text, encoding="utf-8")


def test_replays_finished_run_from_trace_file(monkeypatch, tmp_path):
    monkeypatch.setattr(main, "TRACES_DIR", tmp_path)
    run_id = "a" * 32
    lines = [
        {"ts": "t0", "run_id": run_id, "event": "input",
         "brief": "Sơn chống nóng mái tôn Skyveil", "topics": [TOPIC]},
        {"ts": "t1", "run_id": run_id, "event": "error", "reason": "llm_error", "message": "x"},
    ]
    write_trace(tmp_path, run_id, lines)

    assert events(run_id) == lines


def test_trace_file_without_terminal_event_ends_stream(monkeypatch, tmp_path):

- [ ] **Step 6: Viết lại `src/App.tsx` và `src/index.css`**

State: `events: TraceEvent[]`, `runId: string | null`, `status: 'idle' | 'running' | 'done' | 'failed'`, `notice: string | null` (lỗi POST hoặc mất kết nối).

- Form: `<label>` + `<textarea>` brief (`required`, `maxLength={20000}`, `rows={12}`), 3 `<input>` chủ đề (ô đầu `required`), nút **"Chạy UC-01"** bị khoá khi `status === 'running'`. Submit thì đóng `EventSource` cũ (nếu có), reset state, `startRun` rồi `watchRun`. Mỗi event được thêm vào `events`; event `output` thì `status = 'done'`, `error` thì `status = 'failed'`. `onLost`: `notice = "Mất kết nối tới run {runId}."`, `status = 'failed'`. `watchRun` đã `close()` khi nhận event kết thúc, nên `onLost` không bị gọi sau đó.
- Timeline: `<ol aria-live="polite">`, mỗi event một dòng `{giờ} {mô tả}`. Giờ lấy bằng `new Date(ts).toLocaleTimeString('vi-VN')`. Mô tả lấy từ hàm `describeEvent(e: TraceEvent): string` trong file này:

| `event` | Mô tả |
|---|---|
| `input` | `Nhận brief ({brief.length} ký tự), chủ đề: {topics.join(', ')}` |
| `llm_call` | `Gọi {model}{structured ? ' (chốt kết quả JSON)' : ''}: {input_tokens} token vào, {output_tokens} token ra` |
| `tool_call` | `Tool {name}: {ok ? 'xong' : 'lỗi: ' + error} ({duration_ms} ms)` |
| `skill_invocation` | `Dùng skill {name}` |
| `decision`, `action = repair` | `Output sai schema, yêu cầu sửa lần {attempt}: {error}` |
| `decision`, `action = skip_skill` | `Bỏ qua skill: {reason}` |
| `decision`, action khác | `Quyết định: {action}` |
| `error` | `Lỗi ({reason}): {message}` |
| `output` | `Xong: {prompt_set.prompts.length} prompt` |
| khác | `{event}` |

  Khi `status === 'running'` thì dòng cuối timeline là **"Agent đang chạy…"**.
- Lỗi: khi có event `error`, hiện khung `role="alert"` gồm tiêu đề theo `reason`, dòng `message`, và dòng **"Mã run để tra trace: {run_id}"** (`run_id` trong `<code>`):

| khác (gồm `internal_error`) | `Lỗi không mong đợi` |

  `notice` hiện trong cùng kiểu khung, kèm mã run nếu đã có `runId`.
