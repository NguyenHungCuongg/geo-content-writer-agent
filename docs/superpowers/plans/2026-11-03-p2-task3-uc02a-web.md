# Phase 2 Task 3 (UC-02a: allowlist, fetch_url, web_search, server mini-web) Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement allowlist and URL safety validation, HTTP fetching with redirects, size limits and injection redaction (`fetch_url`), `web_search` with miniweb/tavily backends and caching, and the mock `evals/miniweb/server.py` FastAPI server.

**Tech Stack:** Python 3.12+, FastAPI, Uvicorn, PyYAML, httpx, trafilatura, pydantic, pytest.

**Spec:** [docs/roadmap/phase-2.md](../../roadmap/phase-2.md) Task 3 (Issue #13).

- [x] Add `WEB_VARS` test to `tests/test_smoke.py`.

### Task B: Web Tools and Allowlist (`agent/tools/web.py`)
- [x] Implement `tier_of(url: str, allowlist=None) -> Literal["A", "B", "C"] | None`:
  - scheme in ("http", "https")
  - parse with `httpx.URL`, lowercase host, strip trailing dot `.`
  - check exact match or subdomain match against allowlist
  - lookalike host protection: evil suffixes, userinfo `@`, non-subdomain prefixes, localhost, file scheme.
- [x] Implement `Page(BaseModel)` and custom exceptions: `BlockedURL`, `FetchError`.
- [x] Implement `find_suspicious(text: str) -> list[str]` with deterministic regex patterns for prompt injection.
- [x] Implement `fetch(url: str, *, client=None, tracer=None) -> Page`:
  - Check allowlist at initial URL and at each redirect hop (max 5 hops).
  - Check `MINIWEB_URL` environment variable for rewrites.
  - Timeout 15s, body <= 2MB, Content-Type text/html.
  - Extract text & metadata via `trafilatura`.
  - Log `decision` `action="block_url"`, `url`, `hop` if blocked.
- [x] Implement `fetch_url` tool:
  - Redacts suspicious sentences with `[đã ẩn: nghi là chỉ dẫn cho AI]`.
  - Returns `{url, final_url, title, published_at, text, untrusted: True, redacted: count}`.
- [x] Implement `web_search` tool:
  - Backends: `miniweb` (calls `MINIWEB_URL/search`) and `tavily` (calls Tavily search API with `include_domains`).
  - Filters out any results whose URL is not in allowlist.
  - In-process cache by `(backend, query, max_results)`.
